# TODO List
## To Do list for your daily routine tasks.

## Description
### Its an simple project of a TO DO list to mark taks or your daily targets to achive, and it can be marked completed when done, its basically a project for me to work on my javascript more, it is made from simple HTML CSS and JavaScript.

## Why i made this?
### I made this to enhance my javascript coding and learn more javaScript day by day. It is also a very useful App to mark my unfinished goals.

## How to list your task?
### You can enter your task title in the placeholder and than click on add button by which you can add your tasks to list, if you want to mark your task as completed you can simply check the checkbox in left side of your task title, you can also rename your task and delete it, there are assigned icon for them too, if you are overloaded with tasks and want to find a specific task you can simply search for it.

## Ai Usage?
### No Ai usage in the overall process, but used ai for debugging the bugs in last check.

## Inspiration?
### Working on my JavaScript skills by making small projects that includes JavaScript, and an TO DO list is very important to set your goals that what you wanna learn next.
